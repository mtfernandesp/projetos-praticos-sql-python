# Projetos Acadêmicos - SQL e Python

Repositório de exercícios práticos desenvolvidos na faculdade (CEUB).

## Estrutura do repositório

### exercicio-python/
* **Arquivo:** monitoramento.py
* **Descrição:** Exercício da aula de Introdução à Ciência de Dados para simular o monitoramento térmico de um satélite em órbita LEO.
* **O que foi feito:** Aplicação de lógica para validação e descarte de ruídos de temperatura, classificação do estado térmico do satélite e geração de gráfico da órbita.
* **Ferramenta/Bibliotecas:** Python, Matplotlib e Math.

### exercicio-sql/
* **Arquivo:** IFOOD_SCRIPT.sql
* **Descrição:** Projeto desenvolvido na aula de Banco de Dados I para modelar um sistema de entregas no estilo iFood.
* **O que foi feito:** Modelagem da estrutura (DDL) com tabelas para clientes, entregadores e pedidos, além da manipulação de dados (DML) com comandos de INSERT, UPDATE e DELETE.
* **Ferramenta:** MySQL Workbench.
